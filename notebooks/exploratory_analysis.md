# Exploratory Data Analysis

## Dataset
CDC WONDER Natality — State-Level Data

## Purpose
Conduct an initial exploration of state-level maternal health indicators
to identify patterns, variation, potential data-quality issues, and
variables that may warrant further analysis.

## Initial Questions

1. Which states have the highest and lowest average maternal age?
2. Which states have the highest and lowest average pre-pregnancy BMI?
3. Which states have the highest and lowest average number of prenatal visits?
4. How much does birth spacing vary across states?
5. Are any values missing, suppressed, or otherwise unusual?
6. Are there geographic patterns that warrant further investigation?
